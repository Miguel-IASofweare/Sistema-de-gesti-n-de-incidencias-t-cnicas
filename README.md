# Sistema-de-gestion-de-incidencias-tecnicas
Una empresa necesita una aplicación web para registrar y administrar incidencias técnicas reportadas por Sus usuan0S. Una incidencia representa un problema técnico que debe ser clasificado, asignado, atendido y cerrado.

## Comandos basicos de inicializacion
- cd .\Gestion-Incidencias
- ng serve
